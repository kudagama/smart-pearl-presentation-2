# SLT Smart PEARL - Progress Review Presentation Web App

A modern, sleek, interactive, and responsive presentation web application built with **React 19**, **Tailwind CSS v4**, **Framer Motion**, and **Lucide Icons** for the **SLT Smart PEARL (Enterprise AI Contact Center Copilot & Smart Directory Assistant)** project.

## 🚀 Key Features

- **7-Slide Progress Review Flow**:
  - **Slide 01**: Title & Introduction with animated 3D-like Glowing AI Robot Core & orbital rings.
  - **Slide 02**: Project Overview, Pain Point Bottlenecks, and AI Solution Architecture.
  - **Slide 03**: Progress Summary (100% Planning, 100% Designing, 50% Development, 0% Testing) with workstream drilldowns.
  - **Slide 04**: Key Achievements (Trilingual Speech Normalizer, Sub-0.5s Retrieval, Deterministic Fault Triage, 100% SLT QA Scoring).
  - **Slide 05**: Challenges & Risk Analysis Matrix with impact indicators and proven mitigations.
  - **Slide 06**: Production Roadmap & Phased Delivery Milestones (50-Agent Field Pilot to Island-wide Scale).
  - **Slide 07**: Conclusion & Interactive Q&A with live question submission simulator.
- **Projector-Optimized Readability**:
  - High-impact, large typography readable from the back of an auditorium or conference hall.
  - In-slide card-wise switching and step navigators to avoid dense cognitive clutter.
- **Interactive Controls**:
  - Keyboard navigation (`←`, `→`, `Space`, `Home`, `End`).
  - Dark Mode & Light Mode support.
  - Fullscreen mode & Auto-play mode.
  - Quick Slide Navigator drawer.

## 🛠️ Tech Stack

- **Framework**: Vite + React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Run the dev server
npm run dev

# Build for production
npm run build
```
